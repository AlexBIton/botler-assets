# botler-assets

Public image assets for CHOPS Sigma workbooks (Botler agent icons and OP&A team pictures).

Use the PNG/JPG URLs in Sigma image elements. raw.githubusercontent.com serves SVG as text/plain, so SVG files may not render in Sigma.

Do not rename or move files: the URLs below are referenced from Sigma.
